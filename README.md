# sql_training_log

My SQL practice, one folder per week. I'm working through a self-study plan to move into data/analytics engineering.

Each folder has the .sql files for that week plus a log (README.md) where I note how long each drill took, what I got wrong and what I learned. I've left my wrong attempts in.

Mostly using the Chinook and Northwind sample databases in SQLite, plus small setup scripts written by Claude for specific problems and LeetCode's SQL 50.

- [Week 11](Week_11_SQL/) - production SQL / interview-style drills
- [Week 12](Week_12_SQL/) - self-joins, metric tables and conditional aggregation, anti-joins, timed cold redos and a mock exam
